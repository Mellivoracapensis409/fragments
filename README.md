# Fragments — l'énigme fossile

Jeu de reconnaissance de dinosaures par indices progressifs : un détail, une partie plus large, le contexte, le squelette, puis la reconstitution. Moins on utilise d'indices, plus on marque de points.

- Partie libre (6 manches, filtrables par niveau) et défi du jour
- Fiche de découverte avec indices décisifs, confusions possibles, incertitudes et sources
- Niveau de certitude affiché pour chaque image (fossiles, estimation, hypothèse)

Site statique en un seul fichier : `index.html`. Pour le publier avec GitHub Pages : Settings → Pages → Deploy from a branch → `main` / racine.
